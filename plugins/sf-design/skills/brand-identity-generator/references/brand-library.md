# Reference Brand Library

Use the "Feel" line to describe a brand to the user in plain English. Use the "Design DNA"
line yourself, to derive concrete values for the identity you are generating.

25 brands across 7 categories. Use the "Feel" to describe brands to users. Use the "Design DNA" internally to derive specific values.
